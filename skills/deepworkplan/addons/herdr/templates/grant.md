# Proposed Herdr delegation template

This reasoning aid is reserved for the v7 onboarding and execution hooks.
It does not activate Herdr in v6. The normative grant and reply-stop text
lives in [`../templates.md`](../templates.md); use it verbatim.

Before filling the grant, identify the sender's current machine ID and pane
ID, the receiving peer's stable machine ID and pane ID, the plan task to
delegate, the paths the peer may write, and the acceptance evidence expected
back. Record the delegation in the plan. If the sender's address is unknown,
do not send a prompt that promises a reply route.
